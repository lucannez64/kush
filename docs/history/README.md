# Project history

These documents record how Kush was built: milestone reports, review and
audit records, status ledgers, gate notes and backlogs. They describe the
language and the compiler as they were when written, and are kept for the
reasoning they record, not as a description of the current language.

The current language is [docs/reference](../reference/README.md). Design
documents in [docs](..) keep the rules and the rationale for each feature;
remaining work is tracked in `plan/plan.json`.
